# Datos del proyecto

Esta carpeta contiene los conjuntos de datos utilizados en el análisis exploratorio de fermentación etanólica industrial.

Se trabajó con un **dataset sintético de 6.000 registros**, generado con fines didácticos, que incluye variables operativas, fisicoquímicas, microbiológicas y productivas.

El conjunto original incorporaba deliberadamente valores faltantes, registros duplicados e inconsistencias para ejercitar procedimientos de limpieza y transformación mediante Python en Google Colab.

Después del procesamiento se obtuvo un **dataset de 5.792 registros**, utilizado para realizar el análisis exploratorio y construir los dashboards en Power BI.

Los datos son sintéticos y no corresponden a mediciones de instalaciones industriales reales.
