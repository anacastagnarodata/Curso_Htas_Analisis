# Notebook de análisis exploratorio

Esta carpeta contiene el cuaderno de Google Colab `TP_DataSetFermentacion.ipynb`, donde se desarrolla el procesamiento y análisis exploratorio del dataset sintético de fermentación etanólica industrial.

El trabajo incluye:

- Importación y exploración inicial del dataset.
- Limpieza y normalización de datos, identificación de duplicados, tratamiento de valores faltantes y validación de variables.
- Cálculo de estadísticas descriptivas y correlaciones.
- Elaboración de gráficos utilizando Matplotlib, Seaborn y Plotly.
- Análisis de relaciones entre variables operativas, microbiológicas y productivas.
- Generación automática de un reporte ejecutivo en PDF mediante Python y ReportLab.

El notebook documenta las distintas etapas del análisis y permite consultar el código utilizado, los resultados obtenidos y sus interpretaciones.

**Nota:** El análisis se realizó sobre datos sintéticos con fines didácticos.
