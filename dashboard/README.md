# Dashboards de Power BI

Esta carpeta contiene el informe desarrollado en Power BI Desktop a partir del dataset procesado en Google Colab.

El informe incluye dos dashboards interactivos:

### Dashboard 1. Contaminación bacteriana y estado fisiológico de las levaduras

Permite explorar la relación entre contaminación bacteriana y viabilidad celular, comparar los niveles de contaminación asociados con diferentes tratamientos y observar diferencias entre destilerías y sustratos.

Incluye gráficos de dispersión, gráficos comparativos, indicadores estadísticos y el coeficiente de correlación de Pearson.

### Dashboard 2. Factores asociados al rendimiento fermentativo

Permite analizar las relaciones entre temperatura y rendimiento, concentración inicial de azúcares y etanol final, así como la distribución de los rendimientos y su evolución temporal.

Incluye gráficos de dispersión con líneas de tendencia, coeficientes de correlación, distribución de frecuencias y filtros interactivos.

### Visualización del informe

El archivo `.pbix` puede abrirse con Power BI Desktop para explorar los tableros y utilizar sus filtros.

Los resultados corresponden a datos sintéticos generados con fines didácticos y no representan mediciones industriales reales.
