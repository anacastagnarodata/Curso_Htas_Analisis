# Resultados y conclusiones del proyecto

Esta carpeta reúne los documentos finales correspondientes al análisis exploratorio de datos de fermentación etanólica industrial.

### Conclusiones_Analisis_Fermentacion_Etanolica.pdf

Documento que integra los principales resultados obtenidos mediante Google Colab y Power BI.

Incluye las asociaciones identificadas entre variables microbiológicas, operativas y productivas, las diferencias observadas entre tratamientos y las principales conclusiones sobre el proceso de aprendizaje, junto con las limitaciones del estudio.

### Reporte_Analisis_Fermentacion.pdf

Reporte ejecutivo generado automáticamente mediante Python y la biblioteca ReportLab desde el notebook de Google Colab.

Contiene una introducción al caso de estudio, características del dataset procesado, principales resultados del análisis exploratorio, estadísticas descriptivas y consideraciones sobre el alcance de los resultados.

Ambos documentos son complementarios: el primero desarrolla las conclusiones generales del proyecto y el segundo sintetiza los resultados estadísticos obtenidos durante el análisis.

**Nota:** El proyecto utiliza un dataset sintético con fines exclusivamente didácticos. Sus resultados no constituyen evidencia experimental de procesos industriales reales.
